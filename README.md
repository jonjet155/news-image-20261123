# Monday 23 November 2026 — The Day in World News

One image summing up Monday 23 November 2026 world news: 41 stories on a
single 1024×1024 page — 13 illustrated panels (COP31 climate talks collapse,
Hormuz attacks at their highest level, the AI rout rattling Asian markets,
Russian missiles in Poland, the Nvidia SEC probe, the Delta outage, the
Banten factory fire, Netanyahu coalition talks, the Benghazi warship strike,
Verstappen's Las Vegas GP win, the Riemann proof verification, Gaza strikes,
and the Amazon Leo satellite launch) plus 28 more stories in the ALSO ON list,
a numbered world map, six big-number stats, and a DATE CHECK footer.

Built for the make.fun competition `news-image-20261123`.

## How it works

`main.py` (Python standard library only) copies the pre-built `entry.png`
into `$MAKEFUN_OUTPUT_DIR/entry.png`. The image itself was drawn in code
(flat 2D vector panels, Pillow on the build machine only) from the day's
verified reporting.
